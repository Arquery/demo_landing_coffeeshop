# Bruma Coffee ☕

A responsive landing page for a fictional specialty coffee shop, inspired by a warm, artisanal aesthetic.

This project was built as a frontend portfolio demonstration, translating a UI design created with Google Stitch and Figma into a functional website.

## Tech Stack

- **HTML5** — Semantic page structure
- **CSS3** — Custom styling and responsive layouts
- **Tailwind CSS** — Utility-based styling
- **JavaScript** — Client-side interactions

## Features

- Responsive layout for desktop and mobile devices
- Warm, coffee-inspired visual design
- Product showcase and brand storytelling sections
- Lightweight frontend implementation without a JavaScript framework

## Project Purpose

Bruma Coffee demonstrates the process of turning a visual design into a responsive web experience, with an emphasis on layout accuracy, usability, and frontend implementation.

This is a fictional project created for portfolio purposes. It does not represent a real business or provide live e-commerce functionality.
